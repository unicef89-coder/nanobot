# Prompt Master

A Claude Code mod that rewrites your rough prompt into a clear, specific one before you send it.

- **✨ Prompt Master button** (in the band just above the prompt box): type a rough prompt, tap the button, and the box is replaced with an improved version for you to review and send.
- **Armed mode**: tap the button with an empty box (or on a surface where the mod cannot read your draft, like the mobile app) and your next message is rewritten as it is sent. Tap again to disarm.
- **`/promptmaster <rough prompt>`**: same rewrite from a slash command.

Rewrites keep your intent, names, paths and code; it never adds requirements.
