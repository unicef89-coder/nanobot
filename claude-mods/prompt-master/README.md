# Prompt Master

A Claude Code mod that rewrites your rough prompt into a clear, specific one before you send it.

- **✨ Prompt Master pane** (every app, including mobile): type a rough prompt, tap **✨ Rewrite**, review the better prompt, then tap **➤ Send** (or **Put in box** where the app allows it).
- **Auto toggle** in the pane: when on, your next chat message is rewritten as it is sent.
- **✨ Prompt Master button** above the prompt box (terminal and desktop): rewrites the draft in the box in place.
- **`/promptmaster [rough prompt]`**: opens the pane, and rewrites the prompt if you give one.

Rewrites keep your intent, names, paths and code; it never adds requirements.
