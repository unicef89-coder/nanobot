# Prompt Master

A Claude Code mod that rewrites your rough prompt into a clear, specific one before you send it.

Works everywhere, including the mobile app, through one slash command:

- `/promptmaster <rough prompt>`: rewrites it and shows the better prompt in the chat (and in the Prompt Master panel).
- `/promptmaster send`: sends the last rewrite.
- `/promptmaster auto`: rewrites your next chat message automatically as it is sent.
- `/promptmaster`: shows help and opens the panel.

Also:

- **✨ Prompt Master panel**: rough-prompt field, ✨ Rewrite, ➤ Send and Auto controls (where the app draws text fields).
- **✨ Prompt Master button** above the prompt box (terminal and desktop): rewrites the draft in the box in place.

Rewrites keep your intent, names, paths and code; it never adds requirements.
